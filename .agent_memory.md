# Project Memory

## Context
- React/Vite simulator for robot kinematics using Three.js via `@react-three/fiber` and `@react-three/drei`.
- Backend is a small Express server with SQLite persistence in `database.sqlite`.
- UI lives in `src/App.jsx`; the shared numerical model is `src/kinematics.js`; 3D rendering in `src/RobotScene.jsx` uses the same DH matrices.
- `server/app.js` creates the validated API with an injected SQLite database. `server.js` binds locally; `npm run dev` starts both API and Vite through concurrently. Use PORT/API_PROXY_TARGET/VITE_API_URL for configuration.
- Numerical linear algebra uses ml-matrix SVD. UI joint angles use degrees; revolute rates and the Jacobian use radians. Length uses consistent arbitrary units (u).
- Tests: `npm test` (math and isolated SQLite), `npm run lint`, `npm run build`, `npm run test:e2e` (Playwright). Windows can use PLAYWRIGHT_CHANNEL=msedge; E2E_PRODUCTION=1 tests the built bundle. Browser tests use an in-memory API and dedicated ports 3101/5181.

- Source text in the provided PDFs is embedded as images, so analysis may require rendered page inspection rather than text extraction.

## Hurdles & Solutions
- 2026-09-17: PDF text extraction returned empty output because the lecture files are image-based. Rendered temporary contact-sheet images with PyMuPDF/Pillow and inspected them visually for the system analysis.
- 2026-09-17: The existing RPR DH table describes planar XY position, not a vertical P axis. Verified analytical coordinates and finite-difference Jacobians. Keep task dimension separate from Jacobian column rank: 6x3 rank 3 is underactuated, not automatically singular. Normalized SVD uses row/column length scaling; rank loss alone cannot distinguish structural constraints from configuration singularities.
- 2026-09-17: Browser pixel tests originally created a WebGL context before Three initialized it, defeating preserveDrawingBuffer. Wait for the canvas data-engine attribute before reading pixels. Chromium download timed out; the locally installed Edge provides the same Chromium test engine.
- 2026-09-17: Rolldown chunk groups need explicit positive priority for the Three renderer over the broader Three group. Splitting renderer/core, React and linear algebra removes the large-chunk build warning without raising thresholds.
- 2026-09-17: Inverse solver must record each accepted candidate immediately, including the last allowed iteration. A one-step prismatic regression verifies that reaching tolerance on the final update reports convergence.
- 2026-09-17: Shifting revolute motors along d_i caused non-base motors to detach from the end of preceding links (e.g. prismatic arms with subsequent non-zero d), breaking visual robot continuity. Reverted motor meshes to anchor at frame origins O_(i-1) in RobotScene.jsx. The axial shaft for d extends from the motor along Z_(i-1) to the common normal, maintaining continuous physical link connections for arbitrary DH parameters.
- 2026-09-17: Replaced plain yellow end-effector sphere with a dedicated Gripper 3D component (palm crossbar + two-finger claw with angled tips) in RobotScene.jsx, matching robotic drawing conventions while preserving gold material signature for Playwright pixel-based tests.
